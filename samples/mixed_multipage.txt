【4. 折り返し / Wrapping】
This line is intentionally long so that wrapping can be checked in the generated sample PDF. 長い行の折り返し確認用の文章です。1234567890abcdefghijklmnopqrstuvwxyz 段幅を超えたら次の視覚行へ送られます。The wrapped continuation must stay inside the same column and must not cross the center gap.
次の行も折り返します。IPA Gothic の描画幅で切るため、日本語は全角 1 字、ASCII は実測幅です。ABCDEFGHIJKLMNOPQRSTUVWXYZ abcdefghijklmnopqrstuvwxyz 0123456789 あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろわをん。
English paragraph: The converter expands TAB stops using the width of an ASCII space, counts a fullwidth character as two ASCII columns, and wraps a source line when the measured advance exceeds the column width. この段落は和文と英文を交互に置いて、混在行の折り返し位置を目視できるようにしています。

【5. 手順 / Procedure】
Step 1. 入力ファイルをバイナリで一度だけ読む。Read the input once as bytes.
Step 2. 文字コードを判別する。Detect euc_jis_2004, utf-8, or cp932.
Step 3. 行を段幅に合わせて折り返す。Wrap each line to the column width.
Step 4. 左段、右段の順に描画する。Draw the left column, then the right column.
Step 5. ページを進めてヘッダーとフッターを描く。Advance the page and draw the header and footer.
注意: 8pt でもヘッダーとフッターのサイズは変わりません。Body size changes; header and footer sizes stay fixed.
Note: small is 8pt. Integers from 6 to 16 also set the body size only.

【7. 用語 / Glossary】
1up	A4 portrait, one column. 縦位置・1 段。
2up	A4 landscape, two columns. 横位置・左右 2 段。
leading	font_size * 1.2 + 3。行送り。
column gap	段のあいだの空き。本文はギャップをまたがない。
wrap	段幅を超えたソース行を視覚行へ分割する。
TAB	ASCII 空白幅を 1 桁として次のタブストップまで進める。
encoding	auto の優先順位は euc_jis_2004, utf-8, cp932。
font	本文・ヘッダー・フッターは同じ IPA ゴシック。

確認項目 2: 8pt の本文がヘッダー（ファイル名）やフッター（ページ番号）と重ならないこと。Body text at 8pt must stay between the header rule and the footer rule on every page, including the last partial page.
確認項目 3: 和文の約物「」、（）、英文の comma, period, and slash / が文字化けしないこと。Circled numbers ① through ⑳ and fullwidth digits ０１２３４５６７８９ remain in the embedded font.

確認項目 5: 折り返した行の続きは、次のソース行と区別できること。Wrapped pieces belong to one source line; the following source line starts on its own visual line.
